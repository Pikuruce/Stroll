# Stroll

3Dアクションゲーム「Stroll」のソースコードです。PythonとPanda3Dを使用して制作しています。

## ゲーム概要

キャラクターを操作してフィールドを移動する3Dアクションゲームです。

### アクション

- 通常移動
- ジャンプ
- 二段ジャンプ
- 壁キック
- カメラ操作

## 操作方法

| 操作 | キー |
|---|---|
| 前後左右の移動 | `W` `A` `S` `D` |
| ジャンプ | `Space` |
| カメラ操作 | 矢印キー または マウス |
| カメラ距離の可変化・固定化 | `C` |
| 全画面表示 | `F11` |

## 使用技術

- **言語:** Python
- **ゲームエンジン:** Panda3D
- **実行・環境管理:** uv
- **設定ファイル:** YAML

## 実行方法

### 必要なもの

- Python
- uv

### 起動

プロジェクトのルートディレクトリで、以下のコマンドを実行してください。

```bash
make run
```

### トラブルシューティング

パッケージのインストール時に、ハードリンクの作成に関するエラーが発生する場合は、以下のコマンドを試してください。

```bash
uv run --link-mode=copy main.py
```

このオプションを指定すると、パッケージのインストール時にハードリンクではなくファイルのコピーを使用します。

## 設定

YAML形式の設定ファイルから、ゲームの読み込み方法やデバッグ表示を変更できます。

### `bulk_load`

セクションの読み込み方法を設定します。

| 値 | 動作 |
|---|---|
| `true` | ゲーム開始時にすべてのセクションを読み込みます。初回の読み込みに数分かかる場合がありますが、読み込み後はスムーズにプレイできます。 |
| `false` | 初回の読み込みが短時間で完了します。セクションを移動する際に地形生成が発生し、一時的に画面が停止する場合があります。 |

### `debug`

当たり判定のデバッグ表示を設定します。

| 値 | 動作 |
|---|---|
| `true` | オブジェクトの当たり判定を表示します。 |
| `false` | 当たり判定を表示しません。 |
